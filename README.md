# Economics Exam Notebook

A local study notebook for the Economics for Managers exam.

## What is inside

- Searchable notebook-style website.
- Exam map and syllabus watchlist.
- Supply, demand, equilibrium, circular-flow, and consumption notes.
- Glossary, flashcards, and mixed quiz practice.
- Plain text study notes in `notes.md`.

## How to open

Open `index.html` in a browser.

## Privacy note

The full local version includes course materials and worksheet images. Because this GitHub repository is currently public, those original PDFs and extracted images have not been uploaded here.
